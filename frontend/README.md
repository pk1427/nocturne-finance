# Nocturne Finance frontend

The frontend is the Lace-connected dashboard for the Nocturne Finance Preview MVP.

See the [root README](../README.md) for the deployed contract, current scope, setup instructions, and verification commands.

```bash
npm install
npm run dev
```

Open `http://localhost:3000/app`. The proof server must be running from the repository root first:

```bash
npm run interact-server -- --network preview
```
